# AutoConso Express

## Installation
- **Android** : télécharge AutoConso.apk ci-dessous. Si tu l'as déjà installé, tu n'as rien à refaire : l'application se met à jour toute seule au lancement.
- **iPhone** : ouvre https://tinyurl.com/AutoConso-Express dans Safari, puis Partager > Sur l'écran d'accueil.


Application mobile de suivi de consommation de carburant : vitesse GPS,
consommation en direct, coût du trajet, réservoir virtuel et autonomie.
